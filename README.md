# Fernando Quintero - Astrología Cuántica Kabbalista

Landing page para Fernando Quintero, especialista en **Astrología Cuántica Kabbalista** y creador del método: **Reprogramación Cuántica del Destino**.

## 🚀 Setup

1. Instala las dependencias:
```bash
npm install
```

**Nota:** Si es la primera vez que instalas, asegúrate de que se instalen las nuevas dependencias de Three.js:
- `three`
- `@react-three/fiber`
- `@react-three/drei`

2. Ejecuta el servidor de desarrollo:
```bash
npm run dev
```

3. Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

## 📁 Estructura del Proyecto

- `app/` - Directorio de Next.js con páginas y layouts
- `components/` - Componentes React para la landing page
  - `Header/` - Header con logo
  - `Hero/` - Sección hero principal
  - `SobreFernando/` - Sección sobre Fernando
  - `Metodo/` - Sección del método (3 sesiones)
  - `Resultados/` - Beneficios del proceso
  - `Testimonials/` - Testimonios (placeholder)
  - `CTA/` - Call to action final
- `styles/` - Estilos globales (globals.scss)
- `public/` - Assets estáticos (logo, fuentes, iconos)

## 🎨 Tecnologías

- **Next.js 14** (App Router)
- **React 18**
- **GSAP** para animaciones
- **Three.js** + **React Three Fiber** para gráficos de geometría sagrada
- **SASS/SCSS** para estilos
- **JavaScript** (sin TypeScript)

## 📝 Notas

- El proyecto sigue un enfoque mobile-first
- Las animaciones están implementadas con GSAP ScrollTrigger
- Los estilos usan variables CSS y SCSS según las guías del proyecto
- Las fuentes Gadugi están incluidas en `/public/fonts/`
